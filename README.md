# 21 Savage w/ Authentication 

A great way to practice adding authentication to full stack apps. This code base is older and ripe for debugging. 

## How to navigate 

- Authentication/login: You can sign up or login to enter the site.
- Use the message board to submit messages in the list, autopopulated by backend logic
- Interact with the messages by using the thumbs up and thumbs down button to change the total likes number. 
- You have the option to delete messages as well! 

![screenshot of front page of login](/public/img/loginSavage.png)
![screenshot of the profile page](/public/img/profileSavage.png)

## Features
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, express, MongoDB, passport

## Installation for your own project

1. Clone repo
2. run `npm install`

## Usage

1. run `node server.js`
2. Navigate to `localhost:8080`
